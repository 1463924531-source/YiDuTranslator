# 译读

原生 macOS 翻译助手，面向英语阅读、雅思学习和论文资料。使用 DeepSeek 官方 API，提供快捷查词、句段翻译、截图识字、PDF／Word 对照翻译和主动收藏。模型请求需要使用者自行填写 DeepSeek API Key。

当前版本为 1.0.1，支持 macOS 13 或更新版本。全局划词功能依赖前台应用通过 macOS 辅助功能提供选中文字；不同应用或同一应用的不同视图可能表现不同。

## 开始使用

1. 按下文步骤构建并安装 `译读.app`，打开应用的「设置」。
2. 填写自己的 DeepSeek 官方 API Key，点击「保存密钥」，再点「测试连接」。密钥保存在 macOS 钥匙串。
3. 手动输入、粘贴和文件翻译可直接使用。要读取其他应用中的选中文字，请在设置页打开划词功能，并按系统提示授予「辅助功能」权限。
4. 要使用截图功能，请按系统提示授予「屏幕录制」权限。系统可能要求重新打开应用。
5. 如需固定到程序坞，可右键程序坞中的「译读」图标，选择「选项 → 在程序坞中保留」。

## 常用操作

| 操作 | 结果 |
| --- | --- |
| 选中文字，按 `⌘2` | 查词：中文释义、搭配和双语例句 |
| 选中文字，按 `⌘3` | 翻译句子或段落 |
| `⌥⌘4` | 主动框选截图，在本机识字后翻译或解释图片 |
| 在输入框中按 `⌘Return` | 执行当前查词、翻译或润色操作 |
| 按 Esc | 收起浮窗 |
| 点击程序坞或菜单栏图标 | 打开主窗口 |

以上全局快捷键可以修改和关闭。`⌘2`、`⌘3` 会与部分应用的标签页切换冲突；可在设置里改成 `⌥⌘2`、`⌥⌘3`。

单纯选中文字不会触发任何窗口或翻译。划词取词与浮窗有独立开关：关闭取词时，快捷键只打开手动输入；关闭浮窗时，结果显示在主窗口。无法读取选区时，请主动复制并粘贴，应用不会自动读取旧剪贴板。

1.0.1 扩展了网页选区读取：除当前焦点元素外，也会在同一窗口内检查相关父级和可见网页区域，支持部分网页文本标记选区。解析过程有范围和时间限制，并在返回前检查前台窗口是否变化。这个改进提高了部分网页和 Electron 阅读视图的兼容性，但不能保证所有网页、WPS 视图或受保护输入框都能提供可读的选区。

## 翻译、解释与收藏

- 翻译台提供查词、翻译、润色三种模式。支持自动识别、中译英、英译中，以及日常／学术文体。
- 句子默认只显示译文。点击「解释含义与表达」或输入追问后，才生成解释。
- 可补充上下文；词典主要列常见义项，不保证穷尽所有专业与罕见用法。
- 术语表由用户手动添加。条目按原文到指定译法使用，需要时可另加反向条目。
- 「朗读原文」用于单词或句子的系统发音；「朗读结果」读取译文。
- 点击星标才保存词句。收藏支持搜索、标签、删除、全部导出和按搜索结果导出 CSV。

## PDF 与 Word

- 支持 PDF、DOCX、DOC。拖入文件或通过「导入文件」选择文件。
- PDF 保留来源页码，按提取文本中的空行分隔；无明确段落边界时按页内文本及最长约 3,000 字符切块，不推断原页面上的视觉段落。Word 按可提取的段落组织，过长段落继续切块。
- 可翻译选中片段、按当前设置翻译未完成或设置已变化的片段、取消及重试。每段显示生成时使用的方向与文体；改变设置不会把旧译文标记成新设置的结果。
- 扫描 PDF 使用本机文字识别。双栏、表格、公式、图片、页眉页脚等复杂内容可能需要核对；读取提示会说明处理限制或未识别页。
- 单个文件上限 80 MB、PDF 上限 300 页、提取文字上限 100 万字符。超出时需先拆分文件。
- DOCX 中的页眉、页脚、脚注和尾注附在正文之后；旧式 DOC 依赖 macOS 系统转换器，复杂文件建议先在 WPS 中另存为 DOCX。图片内文字、自动编号、公式和嵌入对象可能缺失或简化。
- 导出为 UTF-8 双语对照 TXT；未完成的段落会明确标记。不还原原文件排版，不覆盖原文件。
- 文件阅读与翻译结果只保留在当前使用期间。需要保留时，请主动导出或收藏。

## 数据与网络

- 不自动保存查询历史。未收藏的文字、译文和截图不在重启后恢复。
- 仅收藏、手动添加的术语和偏好设置持久保存在本机。收藏文件位于 `~/Library/Application Support/YiDuTranslator/favorites.json`。
- 每次主动翻译或解释会将相应文字或图片发送给 DeepSeek 官方服务。截图识字、文件文字提取在本机完成。
- API Key 存储在系统钥匙串，服务标识为 `local.codex.YiDuTranslator`。
- 用量来自 API 返回的数据，费用为估算范围，以官方平台账单为准。没有 API Key 或网络连接时，模型翻译不可用。

## 系统权限与应用更新

应用使用本机临时签名。重新编译后，签名身份可能随程序内容改变。如果系统权限开关显示已开启，但应用仍报告「辅助功能未允许」，可完全退出译读，在系统设置的辅助功能权限列表中移除译读的旧条目，再重新添加 `/Applications/译读.app` 并开启权限。随后重新打开译读并刷新权限状态。只需处理译读的授权条目。

临时签名更新也可能使 macOS 钥匙串重新询问是否允许新版应用读取已保存的 API Key。登录（login）钥匙串密码通常与 Mac 登录密码相同；确认请求来自自己安装的译读后，可选择「始终允许」以减少重复询问。无需因为这一提示重置整个钥匙串。

## 源码与构建

需要 macOS 13 或更新版本、Swift 5.10 或更新版本的命令行构建工具。当前构建脚本面向 Apple Silicon Mac，无第三方包依赖。

```bash
bash scripts/build.sh
bash scripts/install.sh
```

构建产物默认位于项目目录旁边的 `译读.app`；安装脚本复制到 `/Applications/译读.app`。脚本拒绝覆盖同名的其他应用，也会拒绝在已安装的译读仍运行时更新。更新前请用 `⌘Q` 完全退出；签名身份变化时，安装脚本会提示可能需要重新添加辅助功能授权。

应用由使用者在本机编译并临时签名，没有 App Store 分发或开发者公证。

独立校验不需要完整 Xcode：

```bash
bash scripts/verify.sh
./Tests/Standalone/verify-store-state.sh
```

校验使用合成文件与模拟接口，不读取使用者文件或密钥，也不调用真实收费 API。项目另保留 XCTest 测试；如果构建环境只有 Command Line Tools，可运行上述独立校验。

## 验证范围

- 独立校验覆盖 API 流式响应与取消、文档及 OCR 提取、收藏持久化、应用状态、UTF-16 边界和进程取消。选区解析包含 21 项回归检查，其中包括网页容器、文本标记、隐藏元素、受保护输入框、前台窗口变化和遍历上限。
- `⌘2`／`⌘3` 取词依赖目标应用提供的辅助功能信息。不同网页、Electron 应用和 WPS 文档视图需要分别验证；若选区不可读，可使用主动复制、粘贴或截图入口。
- 复杂 PDF／Word 的阅读顺序、OCR 准确率，以及模型翻译质量、响应速度和费用，仍需结合实际文件和官方账单核对。
